## 🌟 ওভারভিউ (Project Overview)

**Instant WhatsApp AI Sales Rep Engine** হলো একটি সম্পূর্ণ স্বতন্ত্র (Standalone) এবং প্রডাকশন-রেডি SaaS ল্যান্ডিং প্ল্যাটফর্ম ও ইন্টারঅ্যাক্টিভ স্যান্ডবক্স। 

প্রতিদিন রাতে শত শত কাস্টমার ফেসবুক ও ই-কমার্স ইনবক্সে মেসেজ দিয়ে ঘুমিয়ে পড়ে এবং সকালের মধ্যে অন্য শপ থেকে কেনাকাটা সম্পন্ন করে। আমাদের এই সেলস ইঞ্জিন যেকোনো স্টোরের ক্যাটালগ মাত্র ২০ সেকেন্ডে স্ক্যান ও মুখস্থ করে ফেলে, সঠিক সাইজ ও কালার গাইড করে, ডিসকাউন্টের আপত্তি নিরসন করে এবং মানুষের কোনো সাহায্য ছাড়াই স্বয়ংক্রিয়ভাবে ক্যাশ অন ডেলিভারি (COD) অর্ডার কনফার্ম করে।

এটি সম্পূর্ণ **Zero External Runtime Dependency** দিয়ে তৈরি—অর্থাৎ কোনো নোড মডিউল বা জটিল সার্ভার সেটআপ ছাড়াই সরাসরি যেকোনো ব্রাউজারে `index.html` ডাবল-ক্লিক করলেই অফলাইনে সম্পূর্ণ ফিচারসহ কাজ করে।

### ২. আল্ট্রা-রিয়ালিস্টিক WhatsApp ওয়েব সিমুলেটর (`js/whatsappSimulator.js`)
- **হেডার ডিজাইন:** ক্লাসিক হোয়াটসঅ্যাপ গ্রিন (`#008069`), স্টোর এভাটার, ভেরিফাইড গ্রিন ব্যাজ (`✓`), এবং লাইভ স্ট্যাটাস (`online` থেকে পরিবর্তিত হয়ে অ্যানিমেটেড `typing...`)।
- **বাস্তবধর্মী ইন্টারঅ্যাকশন টাইমিং:**
  - `0ms` — মেসেজ পাঠানোর সাথে সাথে সিঙ্গেল গ্রে টিক (`✓`)।
  - `200ms` — ডেলিভারি নিশ্চিত হয়ে ডাবল গ্রে টিক (`✓✓`)।
  - `400ms` — রিড রিসিপ্ট হিসেবে ডাবল ব্লু টিক (`✓✓` in `#53bdeb`)।
  - `400ms` — হেডারে সবুজ `typing...` এবং চ্যাটে ৩-ডট জাম্পিং বাবল অ্যানিমেশন।
  - `1000ms - 1200ms` — টাইপিং বাবল দূর হয়ে এআই রেসপন্স বাবল ও ওয়েভ অডিও নোটিফিকেশন চাইম!
- **ইন-চ্যাট রিচ মিডিয়া:**
  - হাই-রেজোলিউশন প্রোডাক্ট কার্ড, ইন-স্টক ব্যাজ, ডিসকাউন্টের হিসাব, স্পেসিফিকেশন এবং `⚡ Order Now with COD` বাটন।
  - সিমুলেটেড অডিও প্লেয়ার ও সিন্থেসাইজড ওয়েব অডিও এপিআই সাউন্ড ইফেক্টস (কোনো বাইরের অডিও ফাইলের প্রয়োজন নেই)।
  - ৩-৪ ইন্টারঅ্যাকশনের পর সরাসরি ক্লোজিং কার্ড:
    > *"আমি তো শুধু আপনার ১০ সেকেন্ডের ডেমো! আপনার আসল হোয়াটসঅ্যাপ নম্বরে এই এআই সেলস রেপ ২৪ ঘণ্টায় চালু করতে নিচে ক্লিক করে জুবায়েরের সাথে কথা বলুন।"*

### ৩. কনভার্সেশনাল সেলস এজেন্ট (`js/aiSalesAgent.js`)
- **দ্বিভাষিক (বাংলা + বাংলিশ):** ন্যাচারাল, প্রফেশনাল, অত্যন্ত আন্তরিক আচরণ।
- **দাম ও ডিসকাউন্ট হ্যান্ডলিং:** কোয়ালিটি ও ভ্যালু বুঝিয়ে অতিরিক্ত অর্ডার আকর্ষণ করা।
- **ক্যাশ অন ডেলিভারি (COD) ফ্লো:** কাস্টমারের নাম, ফোন নম্বর (১১ ডিজিট ভ্যালিডেশন) ও ডেলিভারি ঠিকানা সংগ্রহ করে তাত্ক্ষণিক অর্ডার সামারি রসিদ ও ট্র্যাকিং আইডি প্রদান।

### ৪. ইন্টারঅ্যাক্টিভ আরওআই ক্যালকুলেটর (`#roi-calculator`)
- মাসিক ইনবক্স ভিজিটর, বর্তমান ম্যানুয়াল কনভার্সন রেট (%) এবং গড় অর্ডার মূল্য (AOV) সমন্বয় করে লাইভ হিসাব:
  - রেসপন্স টাইম ৪৫ মিনিট থেকে ০ সেকেন্ডে (ইনস্ট্যান্ট) নেমে আসার প্রভাব
  - বর্তমান মাসিক বিক্রয় vs এআই সেলস রেপ চালুর পর সম্ভাব্য বিক্রয় (২.৮ গুণ বৃদ্ধি)
  - অতিরিক্ত মাসিক সম্ভাব্য রাজস্ব বৃদ্ধি (৳)
  - কাস্টমার সাপোর্ট খরচ সাশ্রয় (-৭০% সাপোর্ট পেরোল রিডাকশন)
  - প্রতি মাসে সাশ্রয়কৃত ম্যানপাওয়ার ঘণ্টা

### ৫. স্বচ্ছ প্যাকেজ ও বাস্তবায়ন প্ল্যান (`#pricing`)
- **স্টার্টার (Starter):** নতুন উদ্যোক্তা ও ফেসবুক পেজের জন্য।
- **গ্রোথ (Growth - মোস্ট পপুলার):** প্রতিষ্ঠিত ই-কমার্সের জন্য আনলিমিটেড ক্যাটালগ ও কুরিয়ার এপিআই কানেক্টর।
- **এন্টারপ্রাইজ (Enterprise):** হাই-ভলিউম ব্র্যান্ডের জন্য কাস্টম ইআরপি ও ডেডিকেটেড অ্যাকাউন্ট ম্যানেজার।

## 🚀 দ্রুত ব্যবহারের নিয়ম (Quick Start)

### অপশন ১: কোনো ডিপেন্ডেন্সি ছাড়া সরাসরি ডাবল ক্লিক (Zero Dependency)
1. এই রিপোজিটরিটি ক্লোন বা ডাউনলোড করুন।
2. সরাসরি `index.html` ফাইলে ডাবল-ক্লিক করুন।
3. আপনার ব্রাউজার (Chrome, Edge, Firefox, Brave) স্বয়ংক্রিয়ভাবে ওপেন হয়ে যাবে এবং সম্পূর্ণ ফিচার সহ অফলাইনেও কাজ করবে।

### অপশন ২: উইন্ডোজ ব্যাচ লাউঞ্চার
- রুট ডিরেক্টরিতে থাকা `run_engine.bat` ফাইলে ডাবল ক্লিক করুন। এটি আপনার ব্রাউজার ওপেন করবে এবং সাথে সাথে ব্যাকগ্রাউন্ডে পাইথন এপিআই সার্ভার চালু করবে।

### অপশন ৩: পাইথন লোকাল সার্ভার
```bash
# sales-engine ডিরেক্টরিতে যান
cd sales-engine

# লোকাল সার্ভার রান করুন (ডিফল্ট পোর্ট 8085)
python server.py 8085
```
এরপর ব্রাউজারে ভিজিট করুন: `http://localhost:8085`

## 🌐 GitHub Pages & Vercel ডেপ্লয়মেন্ট গাইড

### GitHub Pages-এ ১-ক্লিকে ডেপ্লয় করার নিয়ম:
1. আপনার GitHub অ্যাকাউন্টে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `sales-engine` বা `whatsapp-ai-sales-rep`).
2. এই ফোল্ডারের ফাইলগুলো পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "feat: complete standalone whatsapp ai sales rep engine"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. GitHub রিপোজিটরির **Settings** > **Pages** ট্যাবে যান।
4. **Build and deployment** > **Source** হিসেবে `Deploy from a branch` সিলেক্ট করুন।
5. **Branch** হিসেবে `main` এবং ফোল্ডার হিসেবে `/ (root)` সিলেক্ট করে **Save** দিন।
6. ১-২ মিনিটের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে: `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`

### Vercel-এ ডেপ্লয় করার নিয়ম:
1. [vercel.com](https://vercel.com)-এ লগইন করে **Add New Project** সিলেক্ট করুন।
2. আপনার GitHub রিপোজিটরিটি ইমপোর্ট করুন।
3. Framework Preset হিসেবে `Other` রাখুন এবং **Deploy** বাটনে ক্লিক করুন। কোনো বিল্ড কমান্ডের প্রয়োজন নেই।
